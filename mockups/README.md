# Mockupy

Statické HTML mockupy pro odsouhlasení vzhledu. Spuštění: `npm run dev` (otevře `/mockups/news.html`).
CSS a TS jsou rovnou v `assets/front/` a později se napojí na Latte šablony.

Veškerý obsah je **ukázkový**: titulky, perexy, časy i počty článků jsou vymyšlené, i když jsou přiřazené
ke skutečným webům.
